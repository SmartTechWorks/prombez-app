# Промбез: сосуды под давлением

Тренажёр для подготовки к проверке знаний по инструкции «Сосуды, работающие под давлением».
Теория, карточки, тесты (по теме / все / экзамен на 20 вопросов), режим «Расставь по порядку»,
работа над ошибками и прогресс. Работает в браузере телефона, ставится на главный экран,
после первого открытия работает без интернета. Сервера и регистрации нет — всё хранится
в самом телефоне.

Весь учебный материал взят из конспекта и не дополнялся.

## Как открыть на телефоне (Android)

1. Откройте в Chrome адрес приложения: **https://smarttechworks.github.io/prombez-app/**
2. Нажмите меню `⋮` в правом верхнем углу → **«Добавить на главный экран»** (иногда пункт
   называется **«Установить приложение»**) → **«Установить»**.
3. На главном экране появится значок «Промбез». Открывается как обычное приложение,
   без адресной строки.
4. Первый запуск должен быть с интернетом — приложение скачает и запомнит все файлы.
   Дальше работает офлайн.

Прогресс хранится в памяти браузера на этом телефоне. Если очистить данные Chrome
или удалить приложение, прогресс обнулится.

## Как устроено

Чистые HTML/CSS/JS, без сборки. Статика, которую отдаёт GitHub Pages.

```
index.html              оболочка и нижнее меню
styles.css              тема (светлая/тёмная), компоненты
sw.js                   офлайн-кэш; при правках поднять CACHE_VERSION
manifest.webmanifest    установка на главный экран
js/                     экраны: home, theory, cards, quiz, sequence, results, mistakes, progress
js/figures.js           SVG-иллюстрации и иконки
data/topics.json        16 тем: id, название, цвет, иконка
data/theory.json        теория по темам (разделы, списки, плашки с цифрами, таблицы, рисунки)
data/questions.json     вопросы тестов
data/cards.json         карточки
data/sequences.json     задания «расставь по порядку»
img/                    место для фотографий (см. ниже)
tools/check-data.mjs    проверка данных: node tools/check-data.mjs
tools/make-icons.ps1    генерация PNG-иконок
```

## Как добавить вопрос

В `data/questions.json` добавьте объект:

```json
{
  "id": "manometers-22",
  "topic": "manometers",
  "ref": "manometers#diameter",
  "q": "Текст вопроса?",
  "options": ["Правильный", "Неверный 1", "Неверный 2", "Неверный 3"],
  "correct": 0,
  "explain": "Короткое пояснение из конспекта."
}
```

- `topic` — id темы из `topics.json`; `ref` — `тема#раздел` из `theory.json`, по нему строится
  ссылка «Открыть в теории».
- `correct` — индекс правильного варианта в `options` (варианты при показе тасуются).
- Рисунок: `"figure": "pipe", "figureOpts": {"color": "red"}` — id из `js/figures.js`.
- Фото: положите файл в `img/` и укажите `"image": "img/manometer-1.jpg"` — картинка
  покажется вместо рисунка.

Карточки — `data/cards.json` (`id`, `topic`, `q`, `a`). Последовательности —
`data/sequences.json` (`steps` в правильном порядке).

После правок:

```bash
node tools/check-data.mjs
```

и поднимите версию кэша в `sw.js` (`prombez-v1` → `prombez-v2`), иначе телефон будет
показывать старые данные. Затем `git commit` и `git push` — GitHub Pages обновится
через минуту-две, приложение предложит «Обновить».

## Локальный запуск

```bash
python -m http.server 8765
```

и откройте `http://localhost:8765/`. Открывать `index.html` двойным кликом нельзя:
модули и service worker требуют http.
